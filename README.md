# Джунгли / Jungle Chess

Dou Shou Qi для двух игроков на одном устройстве. Первыми ходят синие; эмодзи позже можно заменить фотографическими ассетами в `dist/app.js`.

Запуск: `node server.mjs`, затем http://localhost:8080. Проверка движка: `node --test`.

Статический сайт находится в `dist/`. Движок вынесен в `dist/engine.js` и не зависит от интерфейса. Сервер обслуживает файлы и health endpoints, не требует пакетов. Партия и отмены сохраняются в localStorage. Поддерживаются поворот поля, история, сдача, новая партия и справка.

Правила: слон и крыса едят друг друга; крыса атакует через берег в обе стороны; эффект чужой ловушки применяется первым; лев и тигр прыгают в обоих направлениях; крыса блокирует прыжок; волк сильнее собаки. Ничья после трёх повторений или 100 полуходов без захвата. Онлайн и бот — следующие этапы.
