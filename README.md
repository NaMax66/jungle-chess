# Битва зверей / Jungle Chess

Dou Shou Qi: вдвоём на одном устройстве, с клиентским ботом или с другом по сети по ссылке. Первыми ходят жёлтые. Оформление: тёплая бумага, тушевая сетка, красные и охристо-жёлтые фишки, векторные печати логов и ловушек, волнистые водоёмы с иероглифами. Для движения воды по умолчанию учитывается системная настройка уменьшения движения. Все восемь животных оформлены авторскими тушевыми иллюстрациями на прозрачном фоне; крыса изображена целиком, остальные — портретами. Панель управления доступна в обычном и полноэкранном режимах; история ходов закрыта по умолчанию.

## Локальная работа

Нужен Node.js 22 или новее и `npm install`. Wrangler установлен как dev-зависимость для локальных сетевых комнат; клиенту библиотеки не добавлены.

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Разработка: http://localhost:8080. `PORT` позволяет изменить порт. `dev` обслуживает исходники из `public/` и запускает локальный Worker комнат на 8787; `preview` обслуживает собранный `dist/` (для комнат отдельно запустите `npm run dev:rooms`).

Режим вдвоём на одном устройстве: `/local/` (`public/local/index.html`), со своими русскими метаданными для превью ссылок. Главная `/` — лобби с выбором режима, правил и сложности. Игра с ботом живёт на `/bot/`, с другом по ссылке — на `/online/`. Правила перенаправления в `public/_redirects` используются Cloudflare и локальным сервером.

## GitHub → Cloudflare

Рабочий процесс: изменения → локальный просмотр на http://localhost:8080 → одобрение владельца → проверки → commit → push в `main`. До одобрения изменения остаются локальными, чтобы не ждать публикации Cloudflare на каждой итерации. Подключение репозитория и домен настраивает владелец. Прямой деплой из локальной среды не используется.

Конфигурация следует существующим проектам `word-cards` и `gateway-worker`: Wrangler и Workers Static Assets. Для локального режима и бота сервер не нужен. Сетевые комнаты используют Worker и SQLite-backed Durable Objects на Workers Free, без внешней базы и секретов.

Для **Cloudflare Workers Builds**:

| Параметр | Значение |
| --- | --- |
| Репозиторий | `NaMax66/jungle-chess` |
| Ветка | `main` |
| Корень | `/` |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| Worker name | `jungle-chess` |
| Статические файлы | `dist` (указано в `wrangler.jsonc`) |
| Планируемый домен | `jungle-chess.selfkit.org` |

Альтернатива для **Cloudflare Pages**: та же команда сборки, output directory `dist`, production branch `main`. Отдельная deploy command не нужна. Домен подключается в панели Cloudflare. В конфигурации намеренно нет маршрутов и идентификатора аккаунта.

GitHub Actions проверяет движок и сборку; публикацией управляет настроенная владельцем интеграция Cloudflare.

Документация: [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/).

## Структура и правила

Принятые особенности нашей версии подробно зафиксированы в [RULES.md](RULES.md), включая все сочетания суши и воды при захватах крысы.

- `public/engine.js` — независимый движок игры.
- `public/app.js` — интерфейс и сохранение партии в localStorage.
- `public/style.css` — адаптивное оформление.
- `public/board-theme.css` — палитра и оформление доски по референсам.
- `public/terrain-art.js` — векторные печати, водоёмы и настройка движения воды.
- `public/terrain-guide.js` — карточки реки, ловушки и логова с общими игровыми правилами.
- `public/themes/` — отдельные модули тем с культурными описаниями и иллюстрациями. `html[data-board-theme="classic"]` связывает текущее оформление с классической темой; неизвестная тема получает только общие правила, без текста о нефритовой печати. Переключатель тем пока не реализован.
- `public/piece-motion.js` — плавные ходы, прыжки, захваты и отмена; учитывает системную настройку уменьшения движения.
- `public/board-view.js` и `public/board-view.css` — режим большого поля с видимой очередью хода и компактным управлением. На компьютере панель находится справа, на узком вертикальном экране — снизу. Возврат по кнопке «Свернуть» или Escape.
- `public/music.js` — тихая фоновая музыка по кнопке в шапке, без автозапуска и загрузки до включения. Источник, лицензия и условия атрибуции — в [docs/music.md](docs/music.md).
- `test/engine.test.js` — проверки правил.
- `scripts/build.mjs` — сборка статических файлов.
- `scripts/optimize-art.py` — подготовка WebP из исходных PNG (Python + Pillow): 128/256 пикселей для фишек и списка, 768 пикселей для карточек. Готовые варианты хранятся в репозитории; сборка не требует Pillow. Большой портрет загружается только при открытии карточки.
- `server.mjs` — только локальный сервер; Cloudflare обслуживает файлы самостоятельно.

Поддерживаются допустимые ходы, захваты, прыжки, ловушки, логова, история, отмена хода, поворот поля, сдача и новая партия.

Правила: слон и крыса едят друг друга; крыса атакует через берег в обе стороны; эффект чужой ловушки применяется первым; лев и тигр прыгают в обоих направлениях; крыса блокирует прыжок; волк сильнее собаки. Ничья после трёх повторений или 100 полуходов без захвата. Онлайн и бот — следующие этапы.

## Бот, правила и локальные записи

- `public/rulesets.js`: `battle@1` сохраняет принятые правила, `classic-ymi@1` использует отличия YMI в рангах и захватах. В обоих наборах жёлтые начинают, действуют прежние условия победы/ничьей. Полный снимок правил сохраняется в партии; неизвестные версии не интерпретируются как новые правила.
- `public/bot-search.js`: negamax / alpha-beta с последовательным углублением, оценкой материала, продвижения, мобильности и угроз. Лимиты easy / medium / hard: 2 / 4 / 6 полуходов, 1 800 / 14 000 / 60 000 узлов, 180 / 650 / 1 500 мс. Останавливается при первом достигнутом лимите, использует последнюю полностью рассчитанную глубину. Это начальные уровни, не рейтинг силы.
- `public/bot-worker.js`, `public/bot-client.js`: отдельный Web Worker, отмена устаревших запросов, проверка полученного хода общим движком, повтор при ошибке. Человек играет жёлтыми, отмена возвращает позицию до его хода вместе с ответом бота. Перезагрузка на ходе красных возобновляет расчёт.
- `public/bot/weights-v2.json`: текущая локальная версия коэффициентов (`baseline-2`), совместимая с обоими наборами правил v1/v2. Опубликованный `weights-v1.json` сохранён. Проверяются формат, диапазоны и совместимость с набором правил; есть встроенный fallback. Веса фиксируются на партию. MCTL, обучение, удалённый latest.json и сбор телеметрии пока не подключены.
- `public/game-records.js`: общий архив до 50 партий в localStorage, завершённые и прерванные новой игрой партии; экспорт JSON доступен внутри свёрнутой по умолчанию истории ходов. JSON содержит правила, версию движка/весов, ходы и результат. `replayRecord` воспроизводит и проверяет ходы для будущей фабрики; интерфейс просмотра повтора ещё не добавлен.
- Продолжение игры хранится отдельно: `jungle-chess-v1` для локального режима и `jungle-chess-bot-v1` для бота. Старые локальные сохранения без правил получают `battle@1`. При выборе отличающихся настроек из лобби предлагаем начать новую партию, не стирая текущую автоматически.

Новые партии используют `battle@2` / `classic-ymi@2`: автоматическая ничья после пятого появления одинаковой позиции с той же стороной хода. Начальная позиция учитывается как первое появление. Старые партии и архивы v1 сохраняют порог 3; миграция старого сохранения без набора правил явно выбирает `battle@1`. Ограничение 100 полуходов без захвата не менялось.

## С другом по сети

Из лобби создайте комнату, нажмите «Пригласить друга» и отправьте ссылку. Вход — без регистрации, через кнопку «Сесть за доску». Ключ своего места браузер запоминает отдельно от ссылки. Ходы синхронизируются через сервер; перезагрузка восстанавливает роль. Согласованная отмена и новая партия, сдача, срок жизни 7 дней без действий. Каталог комнат и пароли пока не реализованы.

Архитектура, проверенный тариф Free, лимиты, локальный запуск и публикация: [docs/network/cloudflare-rooms.md](docs/network/cloudflare-rooms.md). `npm run test:rooms` выполняет интеграционную проверку при работающем локальном сервере. Серверные комнаты не используются для обучения бота; обычные локальные партии и бот остаются только в браузере.
