# Битва зверей / Jungle Chess

Dou Shou Qi для двух игроков на одном устройстве. Первыми ходят жёлтые. Оформление: тёплая бумага, тушевая сетка, красные и охристо-жёлтые фишки, векторные печати логов и ловушек, волнистые водоёмы с иероглифами. Для движения воды по умолчанию учитывается системная настройка уменьшения движения. Все восемь животных оформлены авторскими тушевыми иллюстрациями на прозрачном фоне; крыса изображена целиком, остальные — портретами. Панель управления доступна в обычном и полноэкранном режимах; история ходов закрыта по умолчанию.

## Локальная работа

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm run dev
npm test
npm run build
npm run preview
```

Разработка: http://localhost:8080. `PORT` позволяет изменить порт. `dev` обслуживает исходники из `public/`, `preview` — собранный `dist/`.

Режим вдвоём на одном устройстве: `/local/` (`public/local/index.html`), со своими русскими метаданными для превью ссылок. Главная `/` зарезервирована под будущее лобби и пока временно перенаправляет на `/local/` (302). Правила перенаправления в `public/_redirects` используются Cloudflare и локальным сервером.

## GitHub → Cloudflare

Рабочий процесс: изменения → локальный просмотр на http://localhost:8080 → одобрение владельца → проверки → commit → push в `main`. До одобрения изменения остаются локальными, чтобы не ждать публикации Cloudflare на каждой итерации. Подключение репозитория и домен настраивает владелец. Прямой деплой из локальной среды не используется.

Конфигурация следует существующим проектам `word-cards` и `gateway-worker`: Wrangler и Workers Static Assets. Серверный Worker, API, база данных и секреты для этого этапа не нужны.

Для **Cloudflare Workers Builds**:

| Параметр | Значение |
| --- | --- |
| Репозиторий | `NaMax66/jungle-chess` |
| Ветка | `main` |
| Корень | `/` |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| Worker name | `jungle-chess` |
| Статические файлы | `dist` (указано в `wrangler.jsonc`) |
| Планируемый домен | `jungle-chess.selfkit.org` |

Альтернатива для **Cloudflare Pages**: та же команда сборки, output directory `dist`, production branch `main`. Отдельная deploy command не нужна. Домен подключается в панели Cloudflare. В конфигурации намеренно нет маршрутов и идентификатора аккаунта.

GitHub Actions проверяет движок и сборку; публикацией управляет настроенная владельцем интеграция Cloudflare.

Документация: [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/).

## Структура и правила

Принятые особенности нашей версии подробно зафиксированы в [RULES.md](RULES.md), включая все сочетания суши и воды при захватах крысы.

- `public/engine.js` — независимый движок игры.
- `public/app.js` — интерфейс и сохранение партии в localStorage.
- `public/style.css` — адаптивное оформление.
- `public/board-theme.css` — палитра и оформление доски по референсам.
- `public/terrain-art.js` — векторные печати, водоёмы и настройка движения воды.
- `public/terrain-guide.js` — карточки реки, ловушки и логова с общими игровыми правилами.
- `public/themes/` — отдельные модули тем с культурными описаниями и иллюстрациями. `html[data-board-theme="classic"]` связывает текущее оформление с классической темой; неизвестная тема получает только общие правила, без текста о нефритовой печати. Переключатель тем пока не реализован.
- `public/piece-motion.js` — плавные ходы, прыжки, захваты и отмена; учитывает системную настройку уменьшения движения.
- `public/board-view.js` и `public/board-view.css` — режим большого поля с видимой очередью хода и компактным управлением. На компьютере панель находится справа, на узком вертикальном экране — снизу. Возврат по кнопке «Свернуть» или Escape.
- `public/music.js` — тихая фоновая музыка по кнопке в шапке, без автозапуска и загрузки до включения. Источник, лицензия и условия атрибуции — в [docs/music.md](docs/music.md).
- `test/engine.test.js` — проверки правил.
- `scripts/build.mjs` — сборка статических файлов.
- `scripts/optimize-art.py` — подготовка WebP из исходных PNG (Python + Pillow): 128/256 пикселей для фишек и списка, 768 пикселей для карточек. Готовые варианты хранятся в репозитории; сборка не требует Pillow. Большой портрет загружается только при открытии карточки.
- `server.mjs` — только локальный сервер; Cloudflare обслуживает файлы самостоятельно.

Поддерживаются допустимые ходы, захваты, прыжки, ловушки, логова, история, отмена хода, поворот поля, сдача и новая партия.

Правила: слон и крыса едят друг друга; крыса атакует через берег в обе стороны; эффект чужой ловушки применяется первым; лев и тигр прыгают в обоих направлениях; крыса блокирует прыжок; волк сильнее собаки. Ничья после трёх повторений или 100 полуходов без захвата. Онлайн и бот — следующие этапы.
